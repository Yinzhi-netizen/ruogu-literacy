# 若谷自主阅读计划（若谷星河书旅）

若谷的语文识字闯关 PWA。一年级（上下册）+ 二年级（上册，2026-09 录入）词库，按 年级 → 册 → 单元 → 课文 分级出题。

## 当前游戏机制

- 认读关：看到一个词语，从几个拼音里选出正确读音，完成后获得 2 星。
- 听写关：听到语音提示，在 iPad 手写框里写出对应汉字，确认写对后获得 10 星（只出会写词）。
- 阅读关：自己读完一段话或一首诗，完成后获得 5 星（必背课文 / 歌词 / 古诗三类，可按年级筛选）。
- 考试：选中具体课文后点「📝 考这一课」，本课会认词出选择题、会写词出手写听写，每题限时 2 分钟，考完按正确率打分（60 分 +5 星 / 80 分 +10 星 / 满分 +15 星）。
- 星星兑换小人对战时间（50 星 5 分钟）、彩虹防护罩（20 星）、变身（30 星）。

## 数据源

- `grade1-words.js`（RUOGU_OCR）：一年级上下册词库（2026-06-30 家长校对付定稿2）
- `grade2-words.js`（RUOGU_OCR_G2）：二年级上册词库（清澜山《26-27 G2上词语表》）
- `pinyin-data.js` + `grade2-pinyin.js`（RUOGU_PINYIN）：词→拼音，后者由 `tools/build_g2_pinyin.py` 生成后人工校对
- `reading-texts.js`：阅读关文本（含二年级背诵篇目）
- `word-data.js`：统一数据源与词表构建，支持年级/册/单元/课文四级筛选

## 部署

GitHub Pages：`https://yinzhi-netizen.github.io/ruogu-literacy/`

**改代码后记得升 `sw.js` 里的 `cacheName` 版本号**（如 `v35` → `v36`），否则 iPad 旧缓存不更新。

星星与进度存在浏览器 localStorage（`ruogu-literacy-profiles-v1`），换设备用「档案 → 导出/导入」迁移。
