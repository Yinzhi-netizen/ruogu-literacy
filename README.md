# 若谷自主阅读计划（若谷星河书旅）

若谷的语文识字闯关 PWA。一年级（上下册）+ 二年级（上册，2026-09 录入）词库，按 年级 → 册 → 单元 → 课文 分级出题。

## 当前游戏机制

- 认读关：看到一个词语，从几个拼音里选出正确读音，完成后获得 2 星。
- 听写关：听到语音提示，在 iPad 手写框里写出对应汉字，确认写对后获得 10 星（只出会写词）。
- 出题逻辑：**一年级**（旧知复习）按熟练度智能加权——没见过的多出现、错过的优先回来、超 7 天没见的插队、已掌握的偶尔抽查；**二年级**（新课跟学）按课文顺序循环。
- 阅读关：自己读完一段话或一首诗，完成后获得 5 星（必背课文 / 歌词 / 古诗三类，可按年级筛选）。
- 测试：选中具体课文后点「📝 测试」，本课会认词出选择题、会写词出手写听写（测试中不能看答案/重写），每题限时 2 分钟，测完出评估（正确率打分 + 错题清单），可再测一次；60 分 +5 星 / 80 分 +10 星 / 满分 +15 星。
- 星星兑换小人对战时间（50 星 5 分钟）、彩虹防护罩（20 星）、变身（30 星）。

## 作业录音（2026-11）

二年级识字库页面只增加一个「语文作业 · 录音小站」入口，原单元复习列表保持原位。点击入口后进入独立录音视图（`#grade=二上&view=homework`），可点「返回单元复习」或浏览器后退回到目录。录音中离开此视图会自动结束并尝试保存。

填写作业名（可不填）→ 开始录音并允许麦克风 → 停止 → 试听 → 下载音频。iPad 支持文件分享时还会显示「分享 / 存到文件」，由使用者在系统菜单中选择微信或保存到“文件”。

- 优先选择浏览器实际支持的 MP4/AAC（下载扩展名 M4A），其他浏览器按实际支持情况生成 WebM/OGG，文件扩展名与真实编码一致。
- 音频仅保存在当前设备当前浏览器的 IndexedDB `ruogu-homework-audio-v1`；不上传到 GitHub 或服务器。每份录音独立保留，可删除。
- 存储不足时仍提供本次录音试听、下载，并提示立即保存；切到后台会尝试结束并保存已收到的录音。录音时应留在本页并保持屏幕亮着。
- 与星星使用的 localStorage `ruogu-literacy-profiles-v1` 完全独立，不修改档案、星星或进度。
- iPad 使用 HTTPS 线上页面和 Safari；麦克风授权、系统分享菜单与微信接收需在真实 iPad 上验收。

## 数据源

- `grade1-words.js`（RUOGU_OCR）：一年级上下册词库（2026-06-30 家长校对付定稿2）
- `grade2-words.js`（RUOGU_OCR_G2）：二年级上册词库（清澜山《26-27 G2上词语表》）
- `pinyin-data.js` + `grade2-pinyin.js`（RUOGU_PINYIN）：词→拼音，后者由 `tools/build_g2_pinyin.py` 生成后人工校对
- `reading-texts.js`：阅读关文本（含二年级背诵篇目）
- `word-data.js`：统一数据源与词表构建，支持年级/册/单元/课文四级筛选

## 部署

GitHub Pages：`https://yinzhi-netizen.github.io/ruogu-literacy/`

**改代码后记得升 `sw.js` 里的 `cacheName` 版本号**（如 `v35` → `v36`），否则 iPad 旧缓存不更新。

星星与进度存在浏览器 localStorage（`ruogu-literacy-profiles-v1`），换设备用「档案 → 导出/导入」迁移。
